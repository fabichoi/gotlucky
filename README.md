# GotLucky - 점심시간 보드게임 스코어 서비스

## 기간
2025.04 ~ 2025.06

## 배운 것
- Go + Gin 프레임워크
- 스코어 통계 로직
- 배포 경험

## 원래 목표
보드게임 매칭 + 통계 서비스
→ 확장은 안 했지만, 이 아이디어는 여전히 유효함

## 종료 이유
- 실사용자 없음
- 우선순위 밀림
- 그러나 좋은 경험이었음


# 서버 실행 방법 및 가이드 라인

## BE 서버 실행
```
go run ./cmd/main.go
```

## FE 서버 실행
```
npm run
```

## 📌 기본 규칙
- **출근일 포인트 지급**: 매일 100포인트 지급
- **휴가자 포인트 지급**: 하루 75포인트 지급
- **게임 진행 시간**: 점심시간
- **게임 진행 조건**: 참여자가 3명 이상일 경우에만 게임 진행

## 🏆 랭킹 및 상금
- **랭킹 산정일**: 매주 금요일
- **총 상금**: 참여자 1인당 100포인트씩 모아 총 상금 형성
- **상금 분배**:
  - 1등: 총 상금의 50%
  - 2등: 총 상금의 30%
  - 3등: 총 상금의 20%

## ☕️ 벌칙 규칙
- **꼴찌는 벌칙 수행**
- **벌칙 분담 가능**: 다른 한 명을 지목하여 함께 수행 가능
- **제한 조건**: 지난주에 함께 벌칙을 수행한 멤버는 지목 불가
